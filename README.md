# hospital-queue-management-system
Native Android application for efficient hospital queue management, reducing manual patient tracking and improving appointment workflow.

Project Title: Hospital Queue Management System

Technologies Used: Java, Android SDK, Android Room (SQLite), Material Design 3, RecyclerView

Description:

Developed a native Android application for hospital triage and queue management, streamlining patient registration, department assignments, and dynamic waitlist prioritization (e.g., handling emergencies vs. routine checkups).
Integrated Android Room for efficient, persistent local data storage with automated database migrations, ensuring reliable offline functionality and comprehensive patient record management (including search and CSV exports).
Designed a premium, interactive user interface utilizing modern Material Design components and animated statistical dashboards to provide medical staff with real-time insights, solving the problem of disorganized, manual patient tracking and optimizing treatment workflows.
